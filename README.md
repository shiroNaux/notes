# Submodule

To update content inside submodule folder, do the following steps
1. Go to content folder, then pull latest commit
  ``` bash
    cd content
    git pull origin main
  ```
2. Go to root folder and commit new changes
  ```
    git add content
    git commit -m "update submodule"
    git push
  ```
3. Push to Github
